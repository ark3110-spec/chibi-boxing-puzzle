# ちびキャラボクシング～パズル編～

オリキャラのちびキャラ（ボクサー姿）同士が戦う、なぞってつなぐ型のパズル対戦ゲームです。
ブラウザだけで遊べます（インストール不要）。

## 遊ぶ

https://ark3110-spec.github.io/chibi-boxing-puzzle/

PCでもスマホでも遊べます。音が出ます。
